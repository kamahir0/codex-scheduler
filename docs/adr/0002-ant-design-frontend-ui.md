# ADR 0002: Ant Design によるモダンUIシステム

Status: Approved

## 背景（Context）

本ツールは開発者が日常的に利用する生産性ユーティリティであるため、視認性が高く、操作ミスが起きにくく、モダンで快適なUIが求められる。
自作CSSや独自コンポーネントライブラリをゼロから構築すると、テーブルのページネーション、ソート、フィルタ、モーダル、フォームバリデーション、ダークモード対応、通知などの実装コストが膨らみ、品質のばらつきが生じる。

## 決定（Decision）

UIフレームワークとして **Ant Design (`antd` v5/v6)** を採用する。

1. **デザインシステム活用**:
   - `Layout`, `Card`, `Statistic`, `Table`, `Modal`, `Form`, `Timeline`, `Badge`, `Tag`, `Button`, `Space`, `Typography` を全面活用。
2. **テーマシステム**:
   - `ConfigProvider` を用いたダークモード／ライトモードのシームレスな切り替え。
   - 開発者ツールに適したダークテーマ（`theme.darkAlgorithm`）を標準提供。
3. **インタラクション品質**:
   - `Popconfirm` による誤操作防止。
   - `message` / `notification` によるリアルタイムフィードバック。
   - `Tooltip` によるパス等の省略情報補完。

## 結果（Consequences）

- **メリット**:
  - 洗練されたモダンなデスクトップ体験を最小のコード量で高信頼に構築可能。
  - フォームのバリデーションやテーブルの機能（ソート・タグ・アクション）が最初から最高水準で揃う。
  - アクセシビリティとキーボード操作性が標準で担保される。
- **トレードオフ**:
  - React + Ant DesignのバンドルサイズがプレーンHTMLより大きくなるが、Tauriデスクトップアプリのローカル配布においては全く問題にならない。
