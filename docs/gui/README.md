# Canonical GUI Specifications

このディレクトリは、`codex-scheduler` のデスクトップGUIフロントエンドに関する承認済み仕様（Approved behavior）を所有する。
UIフレームワークとして **Ant Design (`antd`)** を採用し、モダンで直感的なデザインと堅牢なインタラクションを提供する。

## GUI Specification Index

- [`app-shell.md`](app-shell.md): ウィンドウ構造、ヘッダー/ナビゲーション、ステータス概要、Ant Designテーマ（ダーク/ライト）。
- [`job-scheduling.md`](job-scheduling.md): ジョブ新規登録モーダル/フォーム、ジョブ一覧テーブル、ステータスバッジ、ログ詳細ドロワー、操作ボタン。
